# 🛡️ Dualex - School Management System

Dualex es una plataforma integral de gestión académica diseñada para optimizar la comunicación y administración entre coordinadores, profesores y alumnos. Con una interfaz moderna, rápida y basada en los últimos estándares de desarrollo.

## 🚀 Tecnologías

El proyecto está dividido en dos partes principales:

### 💻 Frontend (dualex_web)
- **Framework:** Angular 19+
- **Estilos:** Bootstrap 5 & CSS3 Premium
- **Componentes:** Angular DataTables, Bootstrap Icons
- **Animaciones:** Angular Animations

### ⚙️ Backend (dualex_back)
- **Tecnología:** Node.js (Estructura base preparada para escalabilidad)

---

## 📁 Estructura del Proyecto

```text
dualex/
├── dualex_web/      # Aplicación Frontend (Angular)
└── dualex_back/     # API / Lógica de Servidor (Node.js)
```

## 🛠️ Instalación y Ejecución

### 1. Requisitos Previos
- [Node.js](https://nodejs.org/) (Versión 18 o superior recomendada)
- [npm](https://www.npmjs.com/) o [pnpm](https://pnpm.io/)

### 2. Configuración del Frontend
```bash
# Entrar en la carpeta del frontend
cd dualex_web

# Instalar dependencias
npm install

# Iniciar el servidor de desarrollo
npm start
```
La aplicación estará disponible en `http://localhost:4200/`.

### 3. Configuración del Backend
```bash
# Entrar en la carpeta del backend
cd dualex_back

# Instalar dependencias
npm install

# Iniciar el servidor
npm start
```

## ✨ Características Principales

- **Gestión de Usuarios:** Roles diferenciados (Coordinador, Profesor, Alumno).

- **Diseño Responsive:** Adaptado para dispositivos móviles y tablets.
- **Experiencia Premium:** UI limpia con efectos de glassmorphism y transiciones suaves.
