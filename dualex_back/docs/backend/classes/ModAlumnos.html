modAlumnos.php : 13

Modelo de datos para la gestión y persistencia de Alumnos en la base de datos de Dualex.

Esta clase interactúa directamente con las tablas Usuarios, Alumnos y la tabla intermedia Empresa_Alumnos, gestionando la lógica de negocio y transacciones asociadas a los registros de alumnos.
